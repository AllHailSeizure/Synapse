# Synapse commands

| Command | Purpose |
| --- | --- |
| [`/bug`](bug.md) | Capture a bug report with the `bug-capture` skill; kicks `@bug-bandaid` by default unless the user explicitly opts out. |
| [`/weedeat`](weedeat.md) | Survey what accumulated on its own — asset churn in the branch, worktree and branch sprawl — with `asset-churn-audit` and `worktree-cleanup`. Report-only. |
