# Using Synapse

Apply initiative as the baseline operating mode for an established workstream: detect actionable work, resolve authority from current context, execute clearly authorized work, and offer concrete work whose authority is unclear.

Use the focused Synapse skill that matches the task:

- `initiative`: Continue an active workstream and act on authorized opportunities revealed by conversation or accessible artifacts.
- `autonomy`: Execute delegated implementation, debugging, refactoring, research, or batch work through blockers while preserving user-owned intent.
- `goals`: Orient a project around a GitHub milestone or issue when selecting, writing, or fulfilling a goal.

Do not force goal management onto a low-signal first message or informal conversation. Once an authorized workstream exists, do not treat relevant follow-up information as disconnected chat. Keep scope narrow: execute routine work needed for the established outcome and offer separately scoped improvements.
