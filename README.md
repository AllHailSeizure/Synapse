# Synapse for Codex

Synapse is a private Codex plugin for structured, goal-oriented development.

## Included

- `goal-oriented-development` for GitHub milestone and issue workflow.
- Codex agents in `.codex/agents/synapse/` for exploring, surveying, writing, and fulfilling goals.

## Installation

This checkout lives at `C:\Users\nateb\plugins\synapse` and is registered as `synapse` in the personal Codex marketplace. Install or refresh it from Codex's Plugins view; no public marketplace listing is used.

`master` is the shared workshop branch. `codex-release` promotes only Codex files and platform-neutral skills after Claude Code/Codex parity review.
